Conseils et consignes de remplissage

Avant de commencer, prenez quelques minutes pour lire les indications de remplissage. Chaque catégorie contient des aides qui vous guideront dans la saisie.

Commencez par les postes les plus simples et les plus certains, comme les repas, les transports ou le numérique.

Pour remplir le bilan carbone :

  1. Cochez la case « Inclure » pour chaque catégorie qui concerne votre association ou votre événement.
  2. Dans chaque catégorie, vous pouvez ajouter autant d'éléments que nécessaire.
  3. Pour chaque élément ajouté, veillez à remplir tous les champs demandés afin que le calcul puisse être effectué correctement. Pensez également à consulter les aides de remplissage présentes dans chaque catégorie.
  4. Une fois toutes les informations saisies, cliquez sur « Calculer le bilan » pour générer le résultat.
  5. Vous pourrez ensuite télécharger un export Excel contenant le détail du calcul.

Si certaines données ne sont pas encore disponibles, vous pouvez remplir le bilan et revenir plus tard avec la liste des élements par mail à alexandre.poissonneau@efrei.net pour compléter les informations manquantes.

Si vous souhaitez ajouter un élément qui n'existe pas dans les catégories proposées, ou si vous avez un doute sur la manière de renseigner une information, vous pouvez contacter l'équipe Harmony ou votre référent RSE afin que nous puissions vous accompagner ou améliorer l'outil.
